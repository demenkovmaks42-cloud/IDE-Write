# WRITE IDE

**WRITE** — это нативная среда разработки (IDE) под Linux Mint (и другие дистрибутивы Linux), созданная специально для работы с низкоуровневым языком программирования **Sov**. 

Приложение поддерживает интуитивный псевдокод (включая русскоязычные инструкции), автоматическую трансляцию в синтаксис `Sov` и компиляцию в машинный код x86 (32-bit) с выводом ассемблерного листинга.

---

## Системные требования

* ОС: Linux Mint / Ubuntu / Debian
* Python: версии 3.10 или выше (рекомендуется Python 3.13)
* Библиотека графического интерфейса: **PyQt6**
